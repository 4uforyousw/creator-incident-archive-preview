記録の読み方・分類基準

配信者騒動録は、公開情報を出典と時系列に紐づけて整理する記録サイトです。ここで使うラベルは、人物への評価や有罪・違法・虚偽などの判定ではありません。

重要:「公式声明」「一次情報確認済み」という表示は、その声明の中身や争点そのものが真実と確定した、という意味ではありません。誰が何を公表したか、その根拠の出所を区別するための表示です。

騒動の状態

出来事そのものの善悪ではなく、公開情報から確認できる現在の進行状況を表します。

ongoing / 継続中
現在も公式発表、当事者間のやり取り、処分・対応などの更新が続いている状態です。
resolved / 解決・終了
記録上の主要な動きが終了・収束した状態です。事実関係のすべてが合意された、または法的に確定したという意味ではありません。
disputed / 見解相違
重要な点について当事者などの説明・主張が一致していない状態です。
unknown / 不明
公開情報だけでは現在の状態を適切に確定できない状態です。

検証レベル

その記録を公開する際に、どの種類の根拠まで確認できているかを示します。

official / 公式情報
公的機関、裁判資料、公式な運営・組織発表など、公式性の高い資料を中心に記録していることを示します。資料が扱うすべての主張をサイトが独自に認定したという意味ではありません。
primary-source / 一次情報確認済み
本人・当事者の原投稿、原配信、公式声明など、出来事に直接関係する一次情報を確認していることを示します。一次情報に含まれる主張の真実性そのものを保証する表示ではありません。
reported / 報道等で確認
報道などの公開情報によって確認していることを示します。報道内容をサイトが独立に実証したという意味ではありません。
unverified / 未確認
十分な確認が取れていない状態です。このレベルのIncidentは公開できません。

公開時は検証レベルと出典種別の最低限の整合性も確認します。official は所属・運営組織、プラットフォーム、公的機関、裁判資料のいずれかを、primary-source は本人を含む直接・権威的な資料を、reported は報道Sourceを少なくとも1件含む必要があります。補助的に別種別のSourceを併用することは妨げません。

時系列イベントの分類

一つの騒動の中でも、確認済みの出来事と誰かの主張を同じ種類の情報として扱わないための分類です。

confirmed-fact / 確認済み事実
公開された資料から、出来事の発生自体を確認できる事項です。評価・推測・当事者の内心までは含みません。
official-statement / 公式声明
本人、所属先、運営、公的機関などが公式な形で述べた内容です。声明が存在することと、声明内の主張が真実であることは区別します。公開時は誰の声明かを「帰属」として明示し、そのイベント自体が本人・組織・プラットフォーム・公的機関・裁判資料などの直接Sourceを少なくとも1件参照する必要があります。報道による要約は補助Sourceとして利用できますが、それだけで「公式声明」とは分類しません。
third-party-claim / 第三者の主張
第三者が述べている主張・申告・告発などです。公開時は主張者を「帰属」として明示し、主張内容を確認済み事実へ変換しません。
disputed / 争いのある情報
当事者間などで説明が食い違い、争いがあること自体を記録する項目です。公開時は、どの当事者・立場の見解を記録しているかを「帰属」で明示します。
unverified / 未確認情報
調査上把握しているものの、公開上十分な確認が取れていない情報です。draft / reviewでは調査メモとして保持できますが、published Incidentの時系列には含められません。帰属可能な第三者の主張として公開する場合は、根拠Sourceを確認したうえで third-party-claim など適切な分類へ明示的に変更します。

「帰属」は、その発言・主張・見解を誰が示したかを読者が確認できるようにするための表示です。帰属を表示すること自体は、その内容への賛同、真実性の認定、法的評価を意味しません。

出典種別

出典種別は資料の性質を整理する分類です。公開Sourceでは、種別とは別に「発信者」として実際にその資料を発行・投稿した人物・組織・媒体名も表示します。たとえば同じ creator Sourceでも、誰の投稿・配信なのかは発信者欄で区別します。種別や発信者名だけで内容の真実性を自動決定しません。

  • creator / 本人・配信者
  • organization / 所属・運営組織
  • platform / プラットフォーム
  • government / 行政・公的機関
  • court / 裁判資料
  • media / 報道
  • other / その他

分類タグ

タグは騒動の主題を探しやすくするための分類であり、人物評価や違法性・重大性の判定ではありません。URL用の安定IDと日本語表示名を分離しています。

statement / 発言・声明
本人・関係者・所属先などによる発言、声明、説明、謝罪などに関する記録。
contract / 契約・所属
所属、契約、契約終了、活動上の合意や条件などに関する記録。
financial / 金銭
報酬、支払い、返金、売買などの金銭上の争点に関する記録。
copyright / 著作権・権利
著作権、利用許諾、権利処理、コンテンツの使用などに関する記録。
activity / 活動休止・復帰
活動休止、活動再開、配信停止、活動終了などに関する記録。
platform / プラットフォーム対応
配信・投稿プラットフォームによる制限、削除、停止、復旧などに関する記録。
collaboration / コラボ・共演
コラボレーション、共演、共同企画や関係者間の調整に関する記録。
moderation / 運営・モデレーション
コミュニティ運営、モデレーション、イベント運営などの対応に関する記録。
legal / 法的対応
訴訟、開示請求、代理人声明など、公表された法的手続や対応に関する記録。
other / その他
他の分類に適切に収まらない公開上必要な記録。

日付と更新

  • 発生日: 記録対象となる出来事の基準日です。
  • Source公開日: 出典自体の公開日を確認できた場合に表示します。信頼できる公開日を確認できないSourceは「公開日不明」と表示し、内部データには不明と判断した理由を記録します。推測で日付を補いません。
  • 最終更新: Sourceや状態、時系列などを最後に実質的に確認・更新した日です。表示を新しく見せるためだけには変更しません。
  • 編集確認日: その公開版について編集レビューを完了した日です。すべてのpublished Incidentで最終更新日と同日か、それより後でなければなりません。内容の法的・事実的な最終確定を意味する日付ではありません。
  • 訂正・更新履歴: 公開後に意味のある訂正・反論反映・状況更新などを行った場合に残します。

このサイトが自動的には意味しないこと

  • ページが存在すること自体は、その人物に非があるという意味ではありません。
  • 「騒動」という分類は、犯罪・違法行為・契約違反を認定するものではありません。
  • 当事者の声明を掲載することは、その声明内容への賛同や真実性の保証ではありません。
  • 「解決・終了」は、すべての争点が法的・事実的に確定したという意味ではありません。
編集方針掲載判断、出典、表現、高リスク情報の扱いを確認します。訂正・反論・削除について公開後の訂正、反論、削除・非表示の申し出に関する方針です。
